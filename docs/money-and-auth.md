# 本机身份、真实登录与真实资金：当前边界

版本：2026-09-22 · 对应提交 `feat(community)`

这份文档只回答一个问题：**哪些已经做了，哪些必须由后端/资质承接，本仓库刻意不做。**

## 1. 已经实现的部分

| 能力 | 实现方式 | 诚实边界 |
| --- | --- | --- |
| 本机身份 | `src/lib/identityStore.ts`，localStorage `vibe-hall:me` | 离线署名；不是账号，数据不上传 |
| 自建账号 | `server/store.mjs` + `/api/auth/*`，scrypt 密码摘要 + HttpOnly 会话 Cookie | 账号由本站管理；未接邮箱验证、找回和第三方身份提供商 |
| 账号资料 | `/api/profile` + `/#/me` | 昵称、账号、简介和头像色跨设备同步 |
| 个人主页 | `src/pages/MePage.tsx`，聚合我的愿望 / 接单 / 帖子 / 回复 | 统计只覆盖本机数据 |
| 论坛 | `src/lib/forumBoard.ts` + `/#/forum` | 单机版：帖子和回复只有本机能看见 |
| 意向悬赏 | `Wish.bounty`（`src/data/wishTypes.ts`） | 只显示金额与说明；不收款、不支付、不托管、不校验真伪 |
| 积分与徽章 | `src/lib/creditBoard.ts` + `/#/me` | 虚拟点：不可充值/提现、无真实价值；只兑换馆内虚拟徽章 |

### 积分的边界（为什么不算“余额/购买”）

- 积分是**本机记账的虚拟点**：入口只有行为奖励（贴愿望 / 发帖 / 回帖 / 评论 / 接单 / 交付）与开馆赠送，
  没有充值通道、没有提现、没有和法币的兑换比例，也没有任何第三方支付参与。
- “购买”买的是**馆内虚拟徽章**（纯装饰，无实物、无权益、无转赠），余额不足会直接禁用按钮。
- 每笔收支都写进本机流水（`vibe-hall:credits`），可导出 JSON 审计；导出载荷里带
  `disclaimer: 展馆积分是虚拟点，不是钱…`，避免被误当成资金凭证。
- 真实资金部分**依然 blocked**：条件与第 3 节完全一致——主体、资质、渠道、托管、风控、对账、合规。

所有本机数据都可以用「导出本机数据 JSON」（`/#/me`）交给维护者正式收录；这是当前唯一的数据出境方式。

## 2. 仍未覆盖的登录能力

自建账号已经可用，但生产长期运行还需要：

1. 在 GitHub（或别的 IdP）注册 OAuth App，拿到 `client_id`，**`client_secret` 只能放服务端**；
2. 服务端实现回调路由（授权码换 token）+ `state` 校验（CSRF）+ PKCE；
3. 建立用户表与会话（HttpOnly/Secure Cookie 或短期 JWT + 刷新策略）、登出与吊销；
4. 处理账号合并：本机身份（`vibe-hall:me`）如何绑定到真实账号，冲突时以谁为准；
5. 隐私与保留策略：存哪些字段、存多久、如何删除账号。

当前账号登录保护本站自建数据；邮箱验证、密码找回、封禁、审计和第三方 OAuth/OIDC 仍未接入。没有这些能力前，不能把账号当成经过实名验证的身份。

## 3. 真实资金需要什么（当前未做，且不建议自行实现）

悬赏在界面上只是**意向表达**。真要收钱，至少需要：

1. **主体与合规**：谁收款（平台还是个人）、经营范围/ICP、实名与发票、税务申报；
2. **渠道**：微信支付/支付宝/Stripe 等商户号与资质审核；个人开发者通常拿不到平台级收单资格；
3. **资金流设计**：托管或担保交易（先冻结、验收后放款）、部分退款、超时自动取消、争议仲裁规则；
4. **风控与反洗钱**：拒付、刷单、洗钱、未成年人、赌博类需求的拦截与留痕；
5. **账务**：订单、流水、对账文件、审计日志、幂等与补偿（重复回调、掉单）；
6. **数据合规**：支付信息不得进入自有数据库（PCI-DSS），个人信息按《个人信息保护法》最小化收集。

结论：**这部分不建议在没有主体、资质与法务的前提下自己实现**；接入现成平台（如托管式众包平台）比自建更安全。

## 4. 最小恢复条件

- 想要真实登录：提供一个服务端（哪怕是 Serverless 函数）与 OAuth `client_id`，我可以在本仓库加回调、会话与账号绑定，并保持"未登录 = 本机身份"的降级路径。
- 想要真实资金：先确定主体与支付渠道，拿到商户资质后再设计订单与托管流；在这之前，悬赏保持"仅展示"。

当前状态：**自建账号登录 = implemented（仍需补生产运维能力）**，**真实资金 = blocked（缺主体、资质与法务）**；
本机身份、论坛、意向悬赏 = 已实现并已通过测试与浏览器验证。
